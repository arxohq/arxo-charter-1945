# doctrine.iura_humana

Нейтральный словарь заявленного права, допустимого ограничения, средства
защиты и передачи вопроса органу (DECISION-0326). Звенья первой волны —
ВДПЧ (`14-iura-humana.law`), ЕКПЧ ст. 34 и Устав ООН ст. 10. Хартия ЕС не
входит: у владельца ноль `pub`.

Словарь сам молчит: без перевода звена головы остаются `NEITHER`. Один
казус `casus/01-expulsio-sine-iudicio.lawtest` получает три ответа с тремя
якорями; матрица — `casus/matrix.json`.
